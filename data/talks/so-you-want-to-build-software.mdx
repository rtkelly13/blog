# WHAT IS SOFTWARE ENGINEERING?

Every app, website, and game you use was **built by people**.

Software engineering is:

- Turning an idea into instructions a computer can follow
- Solving real problems for real people
- Mostly **thinking and figuring things out** — the typing is the easy bit

It's less like a film hacker, more like **building with invisible LEGO**.

---

# A DAY IN THE LIFE

It is **not** 8 hours of typing code in a dark room.

- ☕ **Morning:** quick team catch-up — what's everyone working on?
- 🧩 **Late morning:** writing code to add a new feature
- 🐛 **Afternoon:** finding out why something broke (and fixing it)
- 👀 **Often:** reviewing teammates' work and explaining ideas

Real number: engineers spend **more time reading and talking than writing new code.**

---

# WHAT DO WE ACTUALLY BUILD?

- 📱 The **apps** on your phone
- 🎮 **Games** and the engines behind them
- 🏥 Systems that run **hospitals, banks, and schools**
- 🚗 Software inside **cars, planes, and even fridges**
- 🤖 The **AI tools** you're starting to hear about

If it has a chip in it, someone wrote the software for it.

---

# IT'S A TEAM SPORT

The biggest myth: that engineers work alone.

- You build things **with** other people — designers, testers, product folks
- You explain your ideas and listen to others
- You disagree, then agree, then ship something better than any one person could

**Communicating clearly is a superpower.** Code is how we talk to computers; words are how we build things together.

---

# SKILLS THAT MATTER (NOT JUST CODE)

You might be surprised:

- 🧠 **Problem solving** — breaking big scary things into small steps
- 🗣️ **Communication** — writing and explaining clearly
- 🔁 **Persistence** — being okay with not knowing... yet
- 🤝 **Curiosity** — asking "but *why* does it work like that?"

Coding can be taught. These are the things that make a *great* engineer.

---

# HOW SOFTWARE GETS MADE

Building software is a **loop**, not a straight line. We ship a small piece, learn from it, and improve.

<Diagram type="mermaid" caption="The build–ship–learn loop">
{`flowchart LR
  A[Idea] --> B[Plan]
  B --> C[Write Code]
  C --> D[Test It]
  D --> E[Ship It]
  E --> F[Get Feedback]
  F --> B`}
</Diagram>

We go around this loop again and again — sometimes many times a day.

# MYTHS vs REALITY

| The Myth | The Reality |
| --- | --- |
| You need to be a maths genius | You need to be a logical thinker |
| You must start coding age 8 | Plenty of us started much later |
| You work alone in a hoodie | It's a hugely social job |
| You have to know everything | You look things up *constantly* |

**Nobody** memorises it all. We Google, we ask, we learn.

---

# HOW DO YOU GET INTO IT?

There's **no single path**. Some routes:

- 🎓 **University** degree in computing — one option, not the only one
- 🛠️ **Apprenticeships** — get paid while you learn, no degree needed
- 💻 **Self-teaching** — free tools online, build your own projects

> Subjects that help: anything that teaches you to **think logically** — maths, sciences, but also music, languages, and art.

The best thing you can do? **Build something small.**

# WHAT I LOVE / WHAT'S HARD

**Love it:**

- Making something from nothing
- Solving a puzzle that beat you yesterday
- Knowing real people use what I built

**Hard bits:**

- Things break, often
- You're always learning (which is also the fun bit)
- Sometimes the bug is *you* 😅

# WANT TO TRY IT?

Free places to start — no money, no fancy computer needed:

- **Scratch** — drag-and-drop coding (scratch.mit.edu)
- **Code.org** — guided lessons and games
- **freeCodeCamp** — build real websites for free
- **Just open a browser** and make a tiny web page today

You don't need permission. You can start **tonight**.
